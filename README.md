# Soshal Server

Soshal is a social network that is cryptographically private of your personal information. It is meant to help get back the internet we were promised.

## Server Code

In the ```server.py``` file, that creates a server on ```0.0.0.0:8000```. It is sompletely set up and ready for API calls by clients. API documentation is available in ```API-Docs.md```.

## GUI Manager

In the ```admin-GUI.py``` file, you can manage accounts on your Soshal network.

## Storage

When running a server, make sure you always have enough space for multiple posts. That always depends on your userbase.
